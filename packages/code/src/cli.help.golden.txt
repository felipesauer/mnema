$ mnema --help

|
| A tamper-evident, local-first audit chain for AI-agent work.
|
| Options:
|   -V, --version                           output the version number
|   -h, --help                              display help for command
|
| Commands:
|   init                                    establish a mnema project in the current directory

|   decision [options] <title> <rationale>  record a decision in the current project
|   skill [options] <name>                  propose a reusable skill in the current project
|   memory [options] <content>              capture a memory in the current project
|   observe [options] <about>               record an observation about an entity in the current project
|   handoff [options] <task> <from> <to>    record a handoff on a task in the current project
|   link [options] <subject> <target>       link one piece of knowledge to another in the current project
|   run                                     open and close the session an agent works inside
|   focus [options]                         show an actor's open runs (what they are touching now)
|   resume [options]                        show where an actor left off (their latest run, open or ended)
|   next-actions [options] <task-id>        show the moves the workflow allows a task next
|   guard [options] <action> <id>           dry-run the gate: would a move be allowed on a task, and if not, why?
|   search [options] [term]                 find what has been recorded, or list the most recent (no term)
|   show [options] <id>                     show one whole record by id (the body a search only pointed at)
|   timeline [options] <id>                 show an entity's history across the trees (subject, about, target)
|   accountability [options]                show who authorized what across the record (optionally windowed/filtered)
|   antipatterns [options]                  show recurring shapes in the record (reopens, supersessions, deprecations)
|   exposure [options]                      show which records hold something shaped like a credential (never the value)
|   refs [options] <id>                     show what an entity is connected to across the trees
|   skills [options]                        show where each pattern came from (who proposed it, who adopted it)

|   key                                     manage this machine's signing keys
|   verify                                  verify the current project's chain
|   mcp [options]                           run the mnema MCP server over stdio (for an agent host)

| show where each pattern came from (who proposed it, who adopted it)
|
| Options:
|   --json      emit the faithful provenance as JSON
|   -h, --help  display help for command
|
| This is the AUDIT of the patterns, not the patterns themselves:

|   This verb reads who put each one there. `mnema show <id>` reads a body.
|   Only an adopted pattern is served to an agent; the other states are not.
|   An act with no agent behind it was a person acting directly.
|   A consultation is one run served the body — not that the work followed it,
|   and counted in this project’s trees and the machine-global one, no other.

### mnema brief --help
$ mnema brief --help
| Usage: mnema brief [options]
|
| print what governs the work here as markdown, for an agent to read
|
| Options:
|   -h, --help  display help for command
|
| It prints to stdout and writes nothing — where the file goes is your choice:
|   mnema brief > AGENTS.md          the record, as the file agent hosts read
|   mnema brief | diff - AGENTS.md   whether that copy still matches the record
|
| The output holds no clock, no session and no path, so the same record always
| prints the same bytes and a difference is a difference in the record.
| It carries this project’s COMMITTED record — what a clone gets. A decision or a
| pattern recorded with `--scope private`, or in your global tree, governs your own
| work and is not in this file, which is written to be committed.
| It carries the RULES and the NAMES: a decision by title and `ADR-<n>` label, a
| pattern by name. Neither body is in it — a decision’s argument and a pattern’s
| text are both `mnema show <id>` (the file itself names the agent’s doors).
| It carries no work list: a queue changes by the hour, and a copy of one in a
| file regenerated by hand would be wrong between two runs.

### mnema key revoke --help
$ mnema key revoke --help
| Usage: mnema key revoke [options] <fingerprint>
|
| retire a key from this identity, from this point forward
|
| Arguments:
|   fingerprint      the full fingerprint of the key to retire
|
| Options:
|   --reason <text>  why it is being retired (recorded in the fact)
|   -h, --help       display help for command
|
| What recording means here:
|   Permanent — mnema is append-only and nothing deletes a fact. A public record
|   is committed and reaches every machine that clones the repository.
|   Do not record credentials: a recognized format is replaced with a placeholder
|   and reported back, but what mnema does not recognize is written verbatim.
|   Each text field holds at most 65536 bytes; a longer one is refused.
