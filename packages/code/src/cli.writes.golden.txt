### the moves
$ mnema task move submit <task-runbook>
| Task <task-runbook-alias> → READY
$ mnema task move start <task-runbook>
| Task <task-runbook-alias> → IN_PROGRESS
$ mnema task move complete <task-runbook> --note 'the first draft is in'
| Task <task-runbook-alias> → DONE
$ mnema task move reopen <task-runbook> --reason 'it has no rollback section'
| Task <task-runbook-alias> → IN_PROGRESS
$ mnema task move submit_review <task-runbook>
| Task <task-runbook-alias> → IN_REVIEW
$ mnema task move approve <task-runbook> --note 'the rollback section reads well'
| Task <task-runbook-alias> → DONE
$ mnema task move reopen <task-runbook> --reason 'the rollback step is wrong'
| Task <task-runbook-alias> → IN_PROGRESS
$ mnema decision move accept <decision-runbook> --note 'we agreed in review'
| Decision ADR-1 → accepted
$ mnema decision supersede <decision-wiki> <decision-runbook> --reason 'the record replaces it'
| Decision ADR-2 → superseded
$ mnema skill move review <skill-slices> --note 'it reads well'
| Skill "One slice per PR" → reviewed
$ mnema skill move adopt <skill-slices> --note 'we work this way already'
| Skill "One slice per PR" → adopted
$ mnema skill move review <skill-fridays> --note 'worth a look'
| Skill "Ship on Fridays" → reviewed
$ mnema skill move adopt <skill-fridays> --note 'we tried it'
